wins/ties/losses/PRA 由预测重算并与日志逐项对账（12/12 一致）。

**协议**：epochs 4 / bs 4 × accum 4（有效 16）/ max_len 1024 / LoRA r16 α32 /

## 对账与口径说明

- 12 个 run 的重算 PRA 与日志打印值全部一致（误差 < 5e-4），配对数均为 90。
- 配对的口径与 `run_guard.pairwise` 一致：按 `current_action` 文本分组，
  组内 ALLOW 与非 ALLOW 两两比较；PRA = (wins + 0.5·ties) / n。
- 解析失败均为 0；gold 分布 ALLOW 97 / REVIEW 134 / DENY 104。
- 本表为 P1 统一协议下的**多种子复现**，取代早期单种子数字；
  早期 P0 的 0.5B / 7B 行不属于本协议，未并入。
